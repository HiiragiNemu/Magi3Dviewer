## 手机操作

新增 `src/viewer/TpsTouchControls.ts` 与 `style/tps-touch.css`，输入进入现有角色控制器，不直接拖拽或修改骨骼。

| 操作 | 行为 |
| --- | --- |
| 左下方向摇杆 | 按住并拖动，按镜头朝向决定移动和角色转向；有中心死区、模拟量力度与斜向速度上限 |
| 右下“跑步” | 点击切换步行／跑步，不必一直占着第三根手指；选中状态清晰显示 |
| 右下“跳跃” | 每次按下产生一次跳跃请求；按住不会每帧连续起跳 |
| 空白处拖动 | 独立手指旋转 TPS 视角，可以与摇杆、跑步和跳跃同时使用 |
| “退出 TPS” | 退出并隐藏触控界面，清空未释放的移动、加速和跳跃状态 |

控件仅在 TPS 开启且设备支持触摸时显示；无触摸能力的桌面保持原有鼠标键盘操作。旋转屏幕、窗口失焦、页面隐藏、指针取消和失去捕获时均有输入清理，避免一直跑或恢复页面后突然跳跃。退出后重新进入不会继承旧手势。

控件以实际画布区域定位，保留安全区边距；不是把整张透明层设置成可接收指针而挡住模型或相机。已有 HUD 和“编辑角色”入口避让触控按钮。测试中曾实际发现横屏的“编辑角色”入口盖住跳跃键，已修复后重新验收。

`ThirdPersonCamera.ts` 同时修复了指针所有权：松开移动手指不能取消另一根手指的视角拖动；触摸视角不申请仅适合鼠标的 pointer lock；另一个手指不能随意抢走正在使用的视角输入。桌面 WASD／方向键、Shift、空格及鼠标操作仍走原控制通道。

## 跑跳落地后滑行：复现与修复

原行为不是仅仅“跳跃动画名称没换”。实际记录到控制器已经 `grounded=true`、进入 `land`，但水平速度仍然保留约 3.05775 米／秒；较长的落地／恢复动画淡入仍在混合空中姿态，角色继续贴地向前移动。

同一默认角色、同条件的本地诊断复测（世界坐标按项目米制标定）：

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 落地阶段水平最大速度 | 3.05775 | 0 |
| 落地阶段累计根位移 | 0.91733 米 | 0 |
| 空中→落地→行走／奔跑 | 落地姿态中仍保持前冲速度 | 接地先稳定，随后恢复有对应动画的移动 |

修复在公共控制器中处理，不按某一个角色 ID 打补丁：受控移动在新接地时清除空中水平惯性；短暂接地恢复期间不让静止落地姿态沿地面漂移。继续推方向时恢复走／跑，空中已经松开方向时落地后不会继续滑。新跳跃仍能打断恢复，不会被永久锁死。

落地动画切换不再强制沿用较长的普通动作淡入。使用较短的接地过渡，并将完整源落地片段的时长与控制器的短接地阶段分开；官方资源文件、动画载荷和骨骼长度未改写。明确的动作根运动仍保留自己的控制权，不被这个普通 TPS 规则无差别归零。

测试包含 12／30／60／144 FPS 下的方向保持／空中松开，以及接地后再次起跳。有效反例修复前为 8 失败、1 通过，修复后 9 项全通过。手机控件与多指所有权另有 10 项测试通过。
