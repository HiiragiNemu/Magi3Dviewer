# 单向衣料接触与触控镜头修复（2026-10-02）

本轮基线：`008e04d6e28b1fa418aedba18bbf69fbc36d74b7`，原工作分支 `magius3dviewer`。针对用户反馈的音梦 102001、灯花 101901 手臂回弹、衣服抖动与腿部穿插，以及双指缩放误滚转。本文发布记录在生产复验后补齐，不以候选测试代替上线结论。

## 根因和权限方向

旧 `StableGarmentContacts.projectArms()` 主动旋转上臂避开衣服，方向错误。旧实际模型验收还把 `^Arm_` 排除在身体不变断言之外。本轮删除了身体回避写入，并修正该验收。衣服只能读取身体作为运动学碰撞体，不得反向改写手、手臂、躯干、腿及根变换。

原方案还有两个不稳定点：碰撞求解失败时整帧撤销全部结果；恢复到接触边界后，再跨过带厚度的边界突然推开。前者造成开/关式跳变，后者造成周期性的接触抖动。本轮不再整帧弹回原姿态，且接触保护间隙同时参与激活和求解评估。

## 两级衣料处理

1. 原生衣料骨骼只承担小幅、被阻尼的整体恢复。默认恢复半衰期 120 ms，设置范围 40–300 ms；修改入口为渲染设置中的“衣服回落阻尼”。没有新弹簧速度、风力或能量累积。衣料骨骼相对于当前原生姿态最多偏离 0.4 rad，并限制额外修正速率；不再为了追上一条腿而猛烈甩动整片裙子。
2. 当前帧的实际局部接触由 `GarmentSurfaceContact` 处理。只选取衣料骨骼占主要权重的衣料顶点，以当前蒙皮变换及其逆变换修正局部衣料位置。非衣料顶点、身体骨骼、UV、权重、材质、源文件均不改写。每个角色使用自己的几何副本，轮廓和阴影共享该角色的实际几何，不是只在颜色画面遮盖穿插。重叠身体碰撞体使用单向出口与局部折叠方向，避免在手与腿之间反复投影。

局部接触在当前帧执行，不等待恢复阻尼。表面位移有按模型腿长归一化的上限；过大或互相压实的接触记录 `limited`，不得改动身体或让衣服无限位移。头发、帽穗、脚链等仍由原有可选原生重力预览负责，不加入新的随机晃动系统。

衣料表面接触在实时/录制骨骼最终姿态之后执行。录制轨道仍保留原生身体动作和已经捕获的骨骼姿态；回放只重新求值派生衣料表面，不把身体重新推开。手动指定的衣料节点继续尊重现有编辑所有权。

## 双指与旋转控件

普通 Orbit 与 TPS 的双指事件只产生缩放和平移，不再产生画面 roll。原有泛用相机平面计算仍可服务明确的旋转指令，不删除镜头功能。PC 和移动端共用一个画面旋转控件：左右拖动旋转，点按恢复水平；旁边保留现有的一次性角色聚焦。控件直接显示操作名称，无需移动端悬停。键盘方向键调整角度，Home 回正。TPS 的 Esc 释放鼠标、双击重新锁定及 Ctrl 平移保持。

## 独立退出与维护回退

- 即时关闭：“稳定防穿模（可单独关闭）”。关闭会恢复本层写入的衣料骨骼和衣料顶点，并清除恢复历史，不触及角色姿态存档或演出项目。
- 构建强制关闭：`MAGIUS_GARMENT_CONTACTS=off npm run build:deploy`（PowerShell 用 `$env:MAGIUS_GARMENT_CONTACTS='off'` 后执行构建）。浏览器偏好不能覆盖构建硬关闭。演出 UI、录制和镜头改动不需要随物理层一起回退。
- 本轮身体、原生走跑跳跃源曲线与原生物理资源没有替换。

## 验证与边界

严格测试覆盖真实手臂/手骨骼、所有非衣料顶点不变；旋转和非均匀缩放下的逆蒙皮修正；同资源多实例隔离；静态反复求值无累计漂移；关闭与手动所有权的精确恢复；帧率无关的被动回落；新碰撞不被大阻尼拖慢；真实触控斜向捏合与回正；PC Ctrl 平移。

真实连续验收记录 Nemu/Touka 行走、奔跑、跳跃、反向行走与停下恢复，并保留早期失败候选。静态图不能替代连续测试。该层仍是与原生骨架配合的近似碰撞约束，不是带布料自碰撞的全网格有限元模拟，也不把碰撞体残余数值直接当作所有像素的视觉认证。验证仅覆盖明确记录的模型/动作/浏览器；不声称全库所有极端姿势零穿插，亦不把桌面触控模拟当作用户真机验收。

## 本地真实模型记录

`one-way-garment-contacts/continuous-contact-review.json` 记录两名角色、五种连续状态（行走、奔跑、跳跃、倒退、停下）的 2,180 帧。所有被检查身体骨骼变换差值和非衣料顶点差值为零。停下后尾段衣料单帧最大角变化：102001 为 0.00277 rad，101901 为 0.00521 rad，包含其原生待机运动；这不是“所有动态部件绝对静止”的声明。

该序列中 102001 的行走/奔跑/倒退以及 101901 的全部记录状态，服装顶点与近似身体碰撞体的最大剩余深度为零。**102001 跳跃局部帧触及表面修正上限，仍记录到最大约 0.0256 模型单位的近似碰撞体残余**。这不应隐藏或标为全场零穿模，也不应通过改动腿姿态、无限拉长衣料或重新猛烈甩动裙子来消除数值。真实像素表现另见同目录运行前后截图，数值只针对所建近似碰撞体。

原来改变上臂的基线证据见 `baseline-body-violation.json`。四个实际模型（102001、101901、100101、100201）的行走/奔跑/跳跃、关闭恢复和姿态重力共 19 组浏览器验收通过，见 `local-model-review.json`。所有姿态开关检查不再豁免上臂。
